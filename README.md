# Juego-GATO-Y-RATON
 Juego en Python donde un ratón y un gato se mueven por un tablero 8x8.
Puedes ser ratón o gato, la IA controla al otro.
Usa w/a/s/d para moverte.
El gato intenta atrapar al ratón; el ratón intenta sobrevivir.
El juego termina si el gato atrapa al ratón o se llegan a 35 turnos.
